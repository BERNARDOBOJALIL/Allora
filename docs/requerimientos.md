# Requerimientos del Sistema

---

# Requerimientos Funcionales

## Comunicación entre usuarios

La aplicación debe permitir la comunicación entre diferentes usuarios mediante mensajes dentro de la plataforma. La comunicación debe realizarse en tiempo real, permitiendo el envío y recepción instantánea de mensajes. Además, los mensajes deben persistir en la cuenta del usuario incluso cuando este no se encuentre en línea.

---

## Conexión mediante preferencias de perfil

La aplicación debe permitir que los usuarios encuentren y generen matches con otros usuarios que compartan gustos, intereses o preferencias similares, favoreciendo conexiones más compatibles y significativas.

---

## Creación y gestión de perfil

La aplicación debe permitir que cada usuario cree y administre su perfil personal. El usuario podrá registrar información básica, preferencias, intereses y una fotografía de perfil para que pueda ser visualizada por otros usuarios dentro de la plataforma.

---

## Localización para emparejamiento

La aplicación debe permitir que el usuario comparta su ubicación con el sistema para delimitar su perfil dentro de comunidades o zonas específicas, facilitando la interacción con usuarios cercanos.

---

## Autenticación de usuarios

La aplicación debe implementar autenticación mediante tokens para proteger las rutas y recursos del sistema contra accesos indebidos o no autorizados.

---

## Notificaciones

La aplicación debe generar notificaciones cuando ocurran eventos relevantes dentro de la plataforma, como la recepción de mensajes, generación de matches o acciones importantes relacionadas con el perfil del usuario.

---

# Requerimientos No Funcionales

## Disponibilidad

El sistema debe mantenerse disponible para los usuarios la mayor parte del tiempo, permitiendo acceso continuo a las funcionalidades principales del SaaS.

---

## Escalabilidad

La arquitectura del sistema debe permitir escalar los servicios de manera independiente, facilitando el crecimiento del sistema conforme aumente la cantidad de usuarios o tráfico.

---

## Seguridad

El sistema debe proteger la información sensible de los usuarios. Las contraseñas deben almacenarse de forma segura y las rutas protegidas deben requerir autenticación y validación mediante tokens.

---

## Persistencia de datos

La información importante del sistema, como usuarios, conversaciones, mensajes, preferencias y notificaciones, debe almacenarse de forma persistente para garantizar continuidad y una mejor experiencia de usuario.
